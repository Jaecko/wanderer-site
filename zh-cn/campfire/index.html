Wanderer Campfire Game

篝火旁的小游戏，由你的旅程滋养

Wanderer Campfire Game 是 Wanderer 为 World of Warcraft Forever 推出的免费扩展。篝火一阶一阶地壮大，同伴们围聚在旁，踏上穿越艾泽拉斯的实时远征。你在游戏中的行动让它更强；它给予的一切只留在它自己的世界里。

下载： CurseForge

免费扩展：需要 Wanderer 0.43 或更高版本，CurseForge 应用会同时安装两者。

I

营地如何成长？

篝火不停地产出余烬，即使你不在也一样（十二小时，有灰烬时更久）。点击拨旺它，购买它的产出者及其强化。凭借余烬和声望，它会经历七个阶段，每一阶都能容纳更多同伴、同时进行更多远征；第七阶永恒烈焰永无止境，每一级的要求都更高。

六座建筑，每座最高五级：厨房提供口粮，铁匠铺增强力量，药剂房医治伤势，帐篷提供空间，仓库增加储量，瞭望塔让带回的收获更多。

II

什么是新的篝火？

当一堆篝火足够壮大时，让它熄灭以换取灰烬。只有篝火重新开始：阶段、建筑、同伴、远征和资源全部保留。每一份灰烬都会永久增强之后的所有篝火，而且只有在两堆篝火之间，才能在灰烬之树中使用它们。

III

同伴是谁？

身披 WoW 职业颜色的冒险者，各自是守护者、治疗者或斗士，并拥有独特的特质。他们在路上升级，在 20、40 和 60 级各选择一个天赋，并穿戴你的铁匠铺为他们打造的装备。常常一起出发的同伴，配合也会更默契。

声望达到崇拜，会让该阵营的一位勇士来到你的篝火旁。

IV

远征如何进行？

选择地点、时长和出发的人选：四十个区域、十九个地下城、七个团队副本。成功几率、所需口粮和预计收获都会在出发前告知。守护者和治疗者很重要，在地下城和团队副本中尤其如此。

远征队实时归来，从十五分钟到一整天不等，带回名望、余烬、物资，有时还有战利品。归来时会有简短提示。偶尔，旅途还会带回一个需要你做出的选择。

V

我真实的游戏进度如何计入？

当你的角色获得某个区域的探索成就，该区域就会向远征开放。你的等级解锁篝火的阶段和地下城。你的专业让营地更强大，军需官也会索要你专业相关的物品：只要放在背包或银行里即可，物品仍归你所有。

每交一个任务都会带来名望，每钓一条鱼、每做一道菜都会带来口粮。你在地下城或团队副本中击杀的首领，会让那里成为亲历之地：那里的远征永久多带回四分之一。

VI

篝火旁会发生什么？

每隔几个小时，篝火旁就会发生一些事：小贩、暴风雨、狼群、吟游诗人。由你做出选择，并承担后果。有些故事会延续三个夜晚。

每个地点都有战利品可寻，还有营地的功绩，以及你崇拜阵营的勇士。

关于 Wanderer Campfire Game 的问题

Wanderer Campfire Game 会在真正的游戏中给予什么吗？

不会。它只读取你的角色做过的事（成就、等级、专业、背包里的物品）；它给予的一切都只留在篝火旁的游戏里。

它会拖慢我的游戏吗？

不会。窗口关闭时不运行任何内容：经过的时间在你查看时才计算，只有一个计时器等待下一支远征队归来。

营地在我的角色之间共享吗？

不共享。每个角色都有自己的营地，由自己的旅程滋养。

如何打开它？

通过 Wanderer 的菜单、游戏按键设置中你自定的按键，或输入 /wcampfire。
